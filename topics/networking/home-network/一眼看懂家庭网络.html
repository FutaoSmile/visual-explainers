02｜LAN 口和 WAN 口，到底怎么分？

字母不用死记，抓住“这个口朝哪边连”。

WIDE AREA NETWORK

WAN 口

广域网口。在家用路由器上，它通常连光猫或上一级网络，是这台路由器的“上游入口”。

例：光猫网口 → 路由器 WAN 口
LOCAL AREA NETWORK

LAN 口

局域网口。通常连电脑、交换机、AP 等家中设备，属于这台路由器管理的本地网络。

例：路由器 LAN 口 → 交换机
记忆口诀：WAN 往外，LAN 留家。 但它们是“相对于某台路由器”的角色，不是所有网线或接口永远固定的身份。

03｜五种角色，各负责什么？

AC 是管理功能，可能独立成设备，也可能集成在路由器里。

🔌

光猫 / ONT

把运营商的光纤接入转换成家里可用的以太网连接。

关键词：光纤入口
🧭

路由器

连接不同网络，决定数据去向；家用场景通常兼做 DHCP 和 NAT。

关键词：网关 / 带路
🧩

交换机

路由器自带的 LAN 口够用就不需要它；口不够时，它能把同一个局域网扩展给更多有线设备。

关键词：按需扩有线口
📶

无线 AP

把有线局域网接入点延伸为 Wi-Fi，让手机等无线设备接入同一网络。

关键词：扩无线覆盖
🎛️

AC / 无线控制器

统一管理多个 AP 的名称、密码和无线参数；不负责替代 AP 发出 Wi-Fi。

关键词：管多个 AP

04｜小米 Mesh 是什么？

它强调多台兼容路由器如何协同覆盖，不是又多出一种必须购买的设备。

小米 Mesh

一台作主路由，其他作子节点，协同提供 Wi-Fi。子节点可用一根网线作回程；若有剩余网口，还能接有线设备。

AC + AP

AP 提供 Wi-Fi 接入；AC 统一管理多个 AP。AC 可能独立成设备，也可能集成在路由器中。

交换机

只负责连接和扩展有线网口，不发 Wi-Fi。可接在主路由与 Mesh 子节点之间，也可接在子节点剩余网口后面。

一根网线怎么接？

主路由 LAN→网线（可经过交换机）→Mesh 子节点上联口
子节点剩余 LAN 口→电脑 / 交换机→更多有线设备

前提是子节点有可用网口。不同小米型号的端口数量、上联口名称和供电方式不同，请以对应说明书为准。

一句话区分：AP 是“发 Wi-Fi 的角色”，Mesh 是“多个节点协同的方法”；交换机则管有线连接。支持 Mesh 的路由器也在充当 Wi-Fi 接入点。

05｜实际接线，按你家的情况选

设备名称相同，工作模式可能不同；先看光猫是否已经负责路由。

光纤→光猫→路由器 WAN→路由器 LAN / Wi-Fi→家中设备

这时路由器通常负责拨号、分配家庭内网地址。它自带的 LAN 口够用就直接接设备；不够再接交换机。桥接光猫虽然可能有多个 LAN 口，但它们未必都能提供同一条上网连接：有的被运营商配置给 IPTV 等业务，具体取决于设备和运营商设置。

光纤→光猫（已路由）→光猫 LAN / Wi-Fi→家中设备

光猫若已经承担路由和 DHCP，它可用的 LAN 口也可以直接接电脑等设备；口够用，就不需要交换机。若还想用另一台无线路由器增加网口或扩大覆盖，可把它设为 AP 模式，并按设备说明接线，这样设备通常仍在同一个局域网。

若光猫和下级路由器都以路由模式工作，常会形成双重 NAT；普通上网通常可用，但端口映射、游戏联机等场景可能更麻烦。
