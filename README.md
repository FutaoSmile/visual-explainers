## 分类规则

- 路径统一为 `topics/<领域>/<专题>/`，例如 `topics/networking/home-network/`。
- 一个专题放一份 `README.md` 作为入口；讲解页、拓扑图及其配套资源放在同一目录，使用相对链接互相跳转。
- 目录名用稳定的英文短名称，不按生成日期拆目录；同一专题更新原有文件，保留 Git 历史。
- 新领域出现时再增加领域目录，并在上表登记；避免提前建空分类。

HTML 文件可以下载后直接用浏览器打开。GitHub 文件预览不会运行 HTML 中的交互，请在本地打开文件体验动画和点击功能。
