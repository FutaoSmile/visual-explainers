02｜LAN 口和 WAN 口，到底怎么分？

字母不用死记，抓住“这个口朝哪边连”。

WIDE AREA NETWORK

WAN 口

广域网口。在家用路由器上，它通常连光猫或上一级网络，是这台路由器的“上游入口”。

例：光猫网口 → 路由器 WAN 口
LOCAL AREA NETWORK

LAN 口

局域网口。通常连电脑、交换机、AP 等家中设备，属于这台路由器管理的本地网络。

例：路由器 LAN 口 → 交换机
记忆口诀：WAN 往外，LAN 留家。 但它们是“相对于某台路由器”的角色，不是所有网线或接口永远固定的身份。

03｜五种角色，各负责什么？

AC 是管理功能，可能独立成设备，也可能集成在路由器里。

🔌

光猫 / ONT

接入运营商光纤；可桥接转发，也可能兼做路由与宽带拨号。

关键词：光纤入口
🧭

路由器

连接不同网络，决定数据去向；家用场景通常兼做 DHCP 和 NAT。

关键词：网关 / 带路
🧩

交换机

路由器自带的 LAN 口够用就不需要它；口不够时，它能把同一个局域网扩展给更多有线设备。

关键词：按需扩有线口
📶

无线 AP

把有线局域网延伸为 Wi-Fi；供电方式可能是适配器、PoE 或两者兼容。

关键词：扩无线覆盖
🎛️

AC / 无线控制器

统一管理多个 AP 的名称、密码和无线参数；不负责替代 AP 发出 Wi-Fi。

关键词：管多个 AP

04｜Mesh、AP 与走动时的切换

Mesh 强调兼容节点的协同；AP 是提供 Wi-Fi 接入的设备角色。两种方案都可以改善多房间覆盖。

小米 Mesh

一台作主路由，其他作子节点，协同提供 Wi-Fi。子节点可用一根网线作回程；若有剩余网口，还能接有线设备。

AC + AP

AP 提供 Wi-Fi 接入；AC 统一管理多个 AP。AC 可能独立成设备，也可能集成在路由器中。

交换机

只负责连接和扩展有线网口，不发 Wi-Fi。可接在主路由与 Mesh 子节点之间，也可接在子节点剩余网口后面。

一根网线怎么接？

主路由 LAN→网线（可经过交换机）→Mesh 子节点上联口
子节点剩余 LAN 口→电脑 / 交换机→更多有线设备

前提是子节点有可用网口。不同小米型号的端口数量、上联口名称和供电方式不同，请以对应说明书为准。

一句话区分：AP 是“发 Wi-Fi 的角色”，Mesh 是“多个节点协同的方法”；交换机则管有线连接。支持 Mesh 的路由器也在充当 Wi-Fi 接入点。

走到另一个房间，会自动换节点吗？

可以。兼容的小米 Mesh 节点会协同提供 Wi-Fi；多台 AP 配成同一网络名称和安全设置后，终端也可能自行漫游，兼容的 AC / AP 漫游功能还能提供辅助。通常无需手动重连，但不保证每次都完全无感。正在通话、游戏或视频会议时，仍可能察觉短暂波动。

一定连“最近、网速最快”的节点吗？

不一定。终端通常参与决定何时切换和连接哪个节点；信号、干扰、回程质量、设备能力都会影响结果。802.11k/v/r 等功能可帮助缩短或优化切换，但要看节点、终端和配置是否支持。把不同品牌的 Mesh 与 AP 放在一起，也不等于组成同一套协同漫游系统。

AP 的网线会顺便供电吗？

普通路由器 LAN 口通常只提供网络数据，不默认给 AP 供电。AP 的供电方式看具体型号：有的接电源适配器，有的支持 PoE 网线供电，也有型号两种都支持。

路由器 / 普通交换机→网线传数据→AP ＋ 电源适配器
路由器 LAN→PoE 交换机或 PoE 注入器→支持对应 PoE 的 AP

买之前核对 AP 所需的 PoE 标准、功率和供电方式；PoE 交换机或注入器负责供电，路由器本身无需有 PoE 功能。

05｜实际接线，按你家的情况选

先看谁负责连接运营商网络。宽带账号密码跟着“拨号的设备”走，不是永远填在光猫里。

光纤→光猫（桥接）→主路由 WAN：PPPoE 账号 / 密码→路由器 LAN / Wi-Fi→家中设备

如果运营商采用 PPPoE，宽带账号和密码填在主路由器的上网设置，由它拨号、分配家庭内网地址；光猫在这里负责光纤接入和桥接转发。主路由 LAN 口够用就直接接设备，不够再接交换机。桥接光猫的多个网口未必都能用于同一条上网连接，有的会被运营商分配给 IPTV 等业务。

光纤→光猫：路由 / PPPoE 拨号（如需）→光猫 LAN→设备 / AP

光猫若已经承担路由和 DHCP，且运营商采用 PPPoE，宽带账号和密码配置在光猫的上网连接里；有些宽带使用自动获取地址等方式，不需要用户填写 PPPoE 账号。光猫可用的 LAN 口能直接接电脑等设备，口够用就不用交换机。另一台无线路由器若只是增加网口或无线覆盖，可按设备说明设为 AP 模式。

若光猫和下级路由器都以路由模式工作，常会形成双重 NAT；普通上网通常可用，但端口映射、游戏联机等场景可能更麻烦。

06｜布网前，先做四个判断

先盘点需求，再决定要不要增加设备；不必把每一种设备都买齐。

① 哪些设备需要有线？

列出电脑、电视、游戏机、NAS 等设备和所在房间，数清需要的网口。主路由的 LAN 口够用就直接接；不够或想在一个房间分出多个口，再加交换机。

② 哪些房间 Wi-Fi 弱？

先看实际使用位置和信号，再按需增加无线 AP 或 Mesh 子节点。能布网线时，可优先考虑有线回程；负责发 Wi-Fi 的设备尽量放在开放位置，别把它藏在金属弱电箱或角落里。

③ 谁负责当主路由？

确认光猫是桥接还是路由模式，再决定下级路由器的工作模式。这样更容易把家中设备放在预期的同一网络，避免无意产生双重 NAT。

④ 线和电源怎么到位？

画出光猫、主路由、各房间网口和无线节点的位置，预留网线与供电。主路由可以同时连接交换机、AP 和 Mesh 子节点；它们都按需求选配。

按需求选设备，不按拓扑图照单购买

覆盖与网口都够→先用现有设备
有线网口不够→加交换机
某些房间 Wi-Fi 弱→优先看布点与网线条件，再选 AP 或兼容 Mesh
多台 AP 要统一管理→考虑支持它们的 AC / 控制器

小户型，覆盖已足够

光猫加一台主路由通常就够。先测常用房间，再决定是否增加设备。

多房间，已经布网线

从主路由 LAN 口或交换机接到各房间网口，按弱覆盖位置增加有线 AP 或支持有线回程的 Mesh 节点；注意节点还需要合适的供电。

多房间，暂时没有网线

可考虑兼容的无线 Mesh；子节点要放在既能收到上级信号、又能覆盖目标房间的位置。无线回程效果受墙体、距离和干扰影响。

装好后怎么验收？

① 每个常用房间都能稳定连接；② 墙上网口和有线设备能正常上网；③ 走动时观察是否切换到更合适的无线节点；④ 确认光猫与下级路由器的模式符合预期，没有无意产生双重 NAT；⑤ 记录设备位置、上联关系和管理入口，方便以后维护。

07｜布网时常见的几个词

先知道它们各管什么，不必一开始就记设置页面里的所有参数。

PPPoE · 宽带拨号

部分运营商用宽带账号和密码验证上网。账号填在负责拨号的光猫或路由器上；并非所有宽带都采用 PPPoE。

DHCP · 自动分配地址

通常由家庭中的主路由负责给手机、电脑等设备分配局域网 IP 地址。

NAT · 多设备共享上网

家庭网关常用它让多个内网设备共用上游连接。光猫和下级路由器都做路由时，可能形成双重 NAT。

SSID · Wi-Fi 名称

就是设备上看到的无线网络名称。相同名称便于使用，但不单凭“名字相同”保证快速、无感漫游。

回程 · 节点之间的连接

Mesh 子节点把流量送回主节点的路径；可走网线，也可按设备能力走无线。回程质量会影响终端体验。

PoE · 网线供电

由兼容的 PoE 交换机或注入器通过网线给 AP 等设备供电。普通交换机或路由器 LAN 口不等于 PoE 口。
