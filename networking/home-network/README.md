# 家庭网络入门与布网指南

这个专题面向准备搭建或调整家庭网络的读者：先认识 LAN / WAN 等常见术语，以及光猫、路由器、交换机、无线 AP、AC 和小米 Mesh 各自的作用；再比较 Mesh 与多 AP 的漫游体验、宽带拨号账号放在哪里、AP 如何供电；最后根据有线设备数量、房间 Wi-Fi 覆盖与现有布线，判断哪些设备值得添加、放在哪里，并检查接线结果。
