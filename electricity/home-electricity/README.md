# 家庭用电图解指南

面向没有电气基础的普通住户。先跟着电表、配电箱、回路、插座与电器的供电路径建立全貌，再认识电压、电流、功率、电量，理解 L、N、PE 三根线及常见保护器的作用。随后用可切换的故障图比较正常、过载、短路、漏电和接触不良，最后学习回路规划、电量估算和异常时的判断。

| 文件 | 用途 |
| --- | --- |
| [一眼看懂家庭用电.html](一眼看懂家庭用电.html) | 十章讲解、闭合回路原理图、可切换的户型回路示例、五种电路状态、电量计算器和小测验 |
| [家庭用电全景拓扑图.html](家庭用电全景拓扑图.html) | 可缩放、可搜索的典型供电关系图 |
| [家庭用电全景拓扑图.architecture.json](家庭用电全景拓扑图.architecture.json) | 拓扑图的 Archify 源规格，便于后续维护 |

两张 HTML 使用相对链接，下载后请放在同一目录。拓扑图中的箭头只表示供电关系，不表示实际线路接法。图示和正文均为教学材料，不是施工图；固定线路、配电箱及保护器的设计、安装和检测应由具备相应资质的专业人员完成。

正文以中国大陆普通住宅为例，具体住宅的回路和保护配置可能不同。关键原理与安全建议的来源列在讲解页末尾。

窄屏上可以在图内左右滑动查看完整原理图；键盘用户可以聚焦图区域后用方向键滚动。户型图仅显示用电点的示例分组，不表示实际墙内线路走向。
