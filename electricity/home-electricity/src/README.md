# 展览源文件

| 文件 | 职责 |
| --- | --- |
| `build.py` | 生成轴测房屋几何、家具、电器与示例线路，并把各源文件嵌入两份独立 HTML |
| `house.svg` | 构建时生成的房屋图形；默认状态由页面交互脚本应用，不要手工改这个文件 |
| `shell.html` | 页面结构、导航、操作台、配电箱与资料弹层 |
| `labs.html` | 交流回路、功率电量仪表、保护器剖解三个 SVG 展品 |
| `styles.css` | 深色展台视觉、状态动效、响应式布局、焦点与减少动态效果支持 |
| `model.js` | 电器和回路数据、供电状态、故障阶段与电量计算；不依赖 DOM |
| `app.js` | 操作事件、视图切换、动画、资料与名词检索；使用同一套供电模型 |
| `model.test.cjs` | Node 原生测试：支路隔离、总闸、三类保护结果、接触不良、规划模型与输入校验 |
| `dom.test.cjs` | 使用 LinkeDOM 执行成品脚本，检查按钮到状态、图形与读数的联动 |
| `verify.py` | 检查唯一 ID、SVG XML、模板展开、链接与离线依赖 |

## 状态约定

- `devices` 保存用户希望开启的设备；`circuits` 与 `main` 决定它们是否真正获得供电。
- 故障视图临时使用实验预设。进入时保存总闸和分路状态，退出时恢复，不覆盖用户的设备选择。
- 规划视图假设各设备请求供电，以便观察整组关系；只有选中回路被突出显示。
- 分组主干按该组是否有负荷显示能量流；每台设备的末端线按它是否真正运行显示能量流，避免关闭电器仍出现供能粒子的误导。
- 隐藏页面或主动暂停会暂停动画与演示计时。减少动态效果偏好下，故障按钮使用逐步查看。

## 验证记录与范围

此次重构通过了 7 项供电和计算模型测试、成品 DOM 事件测试，以及两份 HTML 的结构检查。房屋、闭合回路、仪表与保护器 SVG 单独渲染为图片并进行了目视检查，修正了标签压线等问题。

DOM 测试不模拟浏览器布局，也不能证明 CSS 在所有窗口尺寸下的最终显示。当前验证未包含整页浏览器截图；后续浏览器验收应重点观察 375、768、1024、1440 像素宽度下的导航、操作台、文字换行及键盘焦点。

网页本身无运行依赖。仅 DOM 验证需要 `linkedom`，可通过环境的 `NODE_PATH` 提供，不需要把 `node_modules` 提交到仓库。开发依赖和缓存位置由维护者的环境约定管理。
